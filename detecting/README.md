# Отслеживание объектов в видео с помощью YOLO11

## Why?

Этот скрипт предназначен для обнаружения, отслеживания и вывода названий уникальных классов объектов из видеофайла в режиме реального времени. Программа использует модель YOLO11 от Ultralytics для компьютерного зрения и библиотеку OpenCV для обработки видеопотока.

## Описание

1. Загрузка модели: Скрипт инициализирует нейросеть yolo11n.pt (самая легкая и быстрая модель в линейке).
2. Обработка видео: Покадрово считывается файл rendered_video.mp4.
3. Трекинг (Отслеживание): Модель распознает объекты на каждом кадре и сохраняет их идентификаторы между кадрами (persist=True).
4. Сбор статистики: Названия всех обнаруженных классов объектов добавляются во множество (set), что гарантирует сохранение только уникальных имен.
5. Визуализация: На экран выводится окно с видео, где каждый объект обведен рамкой (bounding box).
6. Финал: При закрытии видео в консоль выводится список всех типов объектов, которые попали в кадр за все время.
