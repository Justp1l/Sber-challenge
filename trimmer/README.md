
# Документация проекта: Фильтрация статичных кадров видео на основе оптического потока

## Why? 

Этот скрипт предназначен для сжатия видеопотока путем удаления из него статичных сцен, когда робот стоит на месте. Скрипт анализирует смещение характерных точек кадра (фич) с помощью алгоритма Лукаса-Канаде (Lucas-Kanade Optical Flow) и перезаписывает в новый файл только те кадры, на которых зафиксировано значимое движение.

## Структура файлов

- `motion_filter.py` (текущий файл) — Логика фильтрации видео по движению и расчет эффективности сжатия.
- `raw_data/output_robot_pov.mp4` — Исходное видео с камеры робота (POV).
- `rendered_video.mp4` — Итоговое сжатое видео, содержащее только моменты движения.

## Алгоритм 

1. Поиск ключевых точек (goodFeaturesToTrack)

Для отслеживания движения на первом кадре (и далее при потере точек) выделяются стабильные углы и контрастные элементы (до 100 штук) с помощью детектора Ши-Томаси.

2. Расчет оптического потока (`calcOpticalFlowPyrLK`)

Для каждого следующего кадра вычисляется смещение ранее найденных точек. На выходе определяются их новые координаты (`good_new`) и статус успешности отслеживания (`st == 1`).

3. Оценка движения и фильтрация

- Скрипт вычисляет среднее абсолютное смещение точек по оси X (`dx_distances -> x_total`).
- Порог фильтрации (`dx_threshold = 5`): Если среднее смещение точек больше 5 пикселей, кадр считается динамичным. Он записывается в итоговое видео, а текущий кадр становится новой опорной базой.
- Если робот стоит на месте (смещение ≤ 5 пикселей), кадр просто пропускается.

## Описание функций

### `main()`

Основная функция, реализующая пайплайн фильтрации видео:
- Инициализирует чтение исходного видео и запись результирующего rendered_video.mp4 с сохранением оригинального разрешения и FPS.
- Конвертирует кадры в оттенки серого (cv2.cvtColor) для работы алгоритмов компьютерного зрения.
- Реализует цикл прохода по видеоряду с динамическим обновлением пула отслеживаемых точек (если их осталось меньше 5).

### `find_difference()`

Функция аналитики. Сравнивает метаданные исходного и сжатого файлов:
- Подсчитывает общее количество кадров в обоих видео.
- Вычисляет абсолютную разницу в кадрах и кратность сжатия.
- Выводит красивый отчет в консоль, показывая количество сэкономленных итераций (кадров, которые теперь не придется обрабатывать тяжелой нейросетью YOLO11 из первого скрипта).
