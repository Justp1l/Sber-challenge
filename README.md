## Семантическое картирование

Семантическое картирование это програмная реализация способности описывать места и объекты при помощи методов ИИ с последющим сохранением и переиспользованием полученной карты, например, для поиска объекта или реализации действия над ним. ## Описание проблемы

В настоящее время, при семантическом картировании, одной из ведущих проблем является проблема с вычислительными возможностями, а также проблема хранения всех объектов и их состояний у себя в памяти. В частности проблема с памятью возникает на длительных сессиях, когда выделенная память под семантическую карту переполнена и начинается перезапись уже существующей карты. Проблемы с вычислениями же однозначны связаны с многозадачностью робота в определённый момент времени [[1]](#bibliography).

## Идейное предложение решения проблемы

1. Не проверять каждый кадр на семантику. Достаточно сравнивать предыдущий кадр и текущий и проверять если он отличается на $\Delta X$, где X - среднее изменение положения каждого пикселя в кадре;
2. Искать и хранить только заданную семантику, в том числе переключатсья по State Machine в случаях, если нужна другая логика;
3. После окончания программы или при **получении задания** повторно сканировать полученные данные для поиска необходимого объекта и строить маршрут (если объект найден по обратным значениям логов).
